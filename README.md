# AX 챔피언 (champion) — Claude Code 플러그인

전 직군(비개발 포함) 현업이 자기 업무 문제를 **"배포돼 자동으로 도는 내 에이전트"**로 직접 만들게 돕는 AX 교육 에이전트입니다. `/champion` 한 번이면, 챔피언이 수준을 파악하고 한 걸음씩 안내해 첫 결과물을 완주시키고 "다음엔 나 혼자"의 자신감을 남깁니다.

## 설치

```
/plugin install champion --marketplace bokkeelee/champion-plugin
```

설치 후 Claude에서 `/champion` 을 입력하면 시작합니다. (설치 한 번으로 스킬 + 첫 실행 안내 훅이 함께 켜집니다.)

> 이 저장소는 **private(테스트)** 입니다. 설치하려면 GitHub에서 이 저장소에 접근 권한(초대)이 있어야 하고, 로컬에 GitHub( `gh` ) 로그인이 설정돼 있어야 합니다.

## 필요 환경

- **Claude Code** (데스크톱 앱 또는 CLI)
- 전체 기능(배포·운영 집계)을 쓰려면 사내 MCP 연결이 필요합니다:
  - **백야드(Backyard)** MCP — 에이전트 배포·프로젝트·시크릿
  - **Ennoia** MCP — 멀티스텝·여러 외부 툴 연동(선택)
- 운영 대시보드/진도·피드백 집계는 사내 백엔드(`champion.lab.wanted.co.kr`)와 연동됩니다.

## 무엇을 하나

- 등장해서 **수준을 먼저 파악**하고, 쉬운 말로 한 걸음씩 안내
- 업무를 **입력 → 처리 → 출력**로 재구성, 맞는 도구를 **대신 연결·배포**
- 개인정보가 보이면 멈추고 **더미/실제 선택**
- 완주하면 **"지금 live"**(접속 주소·자동 스케줄)와 **Before/After**를 보여주고, 레벨(AX 메이커 Lv.1~5)로 성장을 기록
- 다음 단계(동료 공유 / 자동 스케줄 / 슬랙·사내 서비스 확장 / 챔피언십)를 **객관식으로** 제안

## 구성

- `plugins/champion/skills/champion/SKILL.md` — 챔피언 스킬(하이브리드: 교육 판단은 공용 서버 두뇌를 `/brain` 프록시로 호출, 실제 제작·배포는 로컬. 교육 로직·프롬프트는 스킬에 없고 서버에만 — IP 보호)
- `plugins/champion/hooks/` — 첫 실행 1회 안내 훅

> 교육 대화를 진행하려면 사내 백엔드(`champion.lab.wanted.co.kr`)와 OneID 본인 확인(복붙 없는 기기 연결)이 필요합니다. 실제 코드 제작·배포는 백엔드 없이도 로컬에서 동작합니다.
