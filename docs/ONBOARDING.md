# AX 챔피언 — 설치 & 시작 안내

전 직군이 자기 업무를 "배포돼 자동으로 도는 내 에이전트"로 직접 만들어보는 AX 교육 에이전트입니다. 설치 후 `/champion` 한 번이면 시작합니다.

## 1. 설치 (한 번만)

Claude Code(데스크톱 앱 또는 CLI)에서:

```
/plugin install champion --marketplace bokkeelee/champion-plugin
```

- 설치 한 번으로 `champion` 스킬 + 첫 실행 안내가 함께 켜집니다.
- (현재 저장소는 private입니다. 설치하려면 GitHub에서 저장소 접근 권한과 로컬 `gh` 로그인이 필요합니다. 공개 전환 시 초대 없이 바로 설치됩니다.)

## 2. 시작

대화창에 입력:

```
/champion
```

챔피언이 먼저 말을 걸며, 수준을 파악하고 한 걸음씩 안내합니다.

## 3. 본인 확인 (처음 1회, 복붙 없음)

공용 두뇌·AI를 쓰려면 본인 확인이 한 번 필요합니다. 챔피언이 안내하는 링크를 열어 **로그인하고 "연결"만** 누르면 끝 — 코드나 토큰을 직접 복사할 필요가 없습니다.

- **사내(@wantedlab.com)**: 자동으로 허용됩니다(기본 learner, 개인 자율학습 가능).
- **외부 참가자**: 운영자가 먼저 명단에 등록해야 사용할 수 있습니다(아래 운영자 안내 참고).

## 필요 환경

- **Claude Code** (데스크톱 앱 또는 CLI)
- **사내 망** — 공용 두뇌·운영 백엔드(`champion.lab.wanted.co.kr`)는 사내 망에서 접속합니다. 교육은 사내 망에서 진행합니다.
- 배포·운영 집계 등 전체 기능을 쓰려면 사내 MCP(백야드·Ennoia) 연결이 필요합니다.

## 운영자·강사 안내

### 외부 참가자 명단 등록
외부(타사 이메일) 참가자는 사용 전에 **명단 등록**이 필요합니다. 상위 관리자가 운영 콘솔에서 등록합니다.

- 운영 콘솔(상위 관리자): `https://champion.lab.wanted.co.kr/manage` — 서비스 전체 현황 + 명단 관리
- "명단 추가"에 참가자 **이메일**, (선택) **클래스/회사**, **역할**을 넣고 추가하면 그 사용자가 두뇌를 쓸 수 있습니다.

### 역할
| 역할 | 설명 | 지정 방법 |
|---|---|---|
| learner | 학습자(개인, 쿼터 적용) | @wantedlab.com 자동, 또는 명단 등록 |
| operator | 강사·회사(운영 대시보드 `/dashboard`) | 명단에서 operator로 등록 |
| admin | 상위 관리자(서비스 전체 `/manage`) | env `ADMIN_EMAILS` 또는 명단에서 admin |

### 현황 보기
- 상위 관리자: `/manage` — 개설 클래스·유저·레벨·배포·피드백, 도구 사용 현황(챔피언 스킬·엔노이아·백야드)
- 강사·회사: `/dashboard` — 담당 그룹 진행·리더보드·완성작
- 학습자 개인: `/me` — 내 진도·완성작
